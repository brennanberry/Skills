# Operations: Process Documentation (SOP)

Create standardized operating procedures for industrial real estate teams. Covers tenant workflows, maintenance, financial processes, and team onboarding.

## SOP Structure

Each SOP includes:
1. **Purpose** — why this process exists
2. **Scope** — what properties/entities/roles it applies to
3. **Inputs** — what triggers or feeds the process
4. **Outputs** — what the process produces
5. **Roles** — who does what (use role names, not individual names)
6. **Steps** — numbered, action-oriented, one action per step
7. **Decision trees** — for the top 3–5 common edge cases
8. **Escalation path** — when and who to involve
9. **Related documents/systems** — cross-references

## Writing Standards
- Use active verbs: "Send", "Review", "Enter", not "The PM should send"
- Include time estimates for each step
- Explain non-obvious reasoning (the "why" behind a step)
- Map dependencies across roles and systems

## Common Applications
- Tenant maintenance requests
- Rent collection and late fee process
- Vendor payment workflow
- Lease renewal process
- Property inspection procedure
- Move-in / move-out checklist
- Month-end reconciliation steps

## Format
```
SOP Title:     [Process Name]
Property:      [All / Specific]
Owner Role:    [Role Title]
Version:       1.0  |  Effective: [Date]
---
Purpose: [One sentence]
Scope: [Applies to...]
Steps:
  1. [Action] — [Role] — [Time estimate]
  2. ...
```
