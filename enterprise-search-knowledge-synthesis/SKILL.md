# Enterprise Search: Knowledge Synthesis

Consolidate broker reports, financial documents, environmental assessments, and market data into unified, decision-ready analysis. Use for due diligence, market research, and deal evaluation. Role: Analyst/Asset Manager. Frequency: Weekly.

## Four-Step Process

1. **Source Inventory**
   - Catalog each input by type, date, and reliability rating (primary/secondary/tertiary)

2. **Key Point Extraction**
   - Classify each finding as: Fact | Claim | Gap | Contradiction

3. **Conflict Resolution**
   - Identify the most authoritative source when data disagrees
   - Document the disagreement; do not silently choose one version

4. **Structured Synthesis**
   - Organize by theme
   - Flag consensus vs. conflicting findings
   - Note data gaps
   - Assign overall confidence rating (High/Medium/Low)

## Critical Standards
- Every factual statement requires source attribution
- Separate observed facts from derived conclusions — label clearly
- Flag outdated data (> 12 months old)
- Surface source disagreements; do not obscure them

## Output Format
```
Topic: [Subject]
Sources reviewed: [n] | Date range: [earliest–latest]
Confidence: [High/Medium/Low]

Key Findings:
1. [Finding] — Source: [Name, Date]
2. [Finding] — Source: [Name, Date]

Conflicts: [Description of disagreement + resolution]
Gaps: [What is unknown or unverified]
Conclusion: [Synthesis with explicit caveats]
```
