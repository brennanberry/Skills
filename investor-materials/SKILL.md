# Investor Materials

Create cohesive fundraising and investor documents — pitch decks, financial models, memos, and accelerator applications. All materials must agree with each other.

## Core Principle
Before drafting anything, establish a single source of truth:
- Key metrics (AUM, returns, portfolio stats)
- Pricing and raise details
- Team roles and titles
- Timelines and milestones

## Workflow
1. Inventory all known facts
2. Identify gaps requiring input
3. Select document type
4. Draft with clear, logical flow
5. Verify all numbers against source of truth

## Document Types

**Pitch Deck** (12-slide structure)
1. Cover 2. Problem 3. Solution 4. Market 5. Product/Strategy 6. Traction 7. Business Model 8. Team 9. Financials 10. Use of Funds 11. Ask 12. Appendix

**One-Pager / Memo**
Concise, claim-focused. Lead with the ask and key metrics. Max 1–2 pages.

**Financial Model**
- Assumptions tab (all inputs in one place)
- Scenarios (base, upside, downside)
- Sensitivity analysis on key drivers
- Returns summary (IRR, equity multiple, distributions)

**Accelerator Application**
Emphasize traction, team unfair advantage, market size.

## Quality Checklist (Before Delivery)
- [ ] All numbers verified and consistent across documents
- [ ] Math checks out (IRR, multiples, totals)
- [ ] All assumptions visible and defensible
- [ ] Narrative is clear without jargon
- [ ] No unverifiable claims or fuzzy metrics
- [ ] Team roles consistent across all materials
