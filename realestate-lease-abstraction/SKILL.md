# Real Estate: Lease Abstraction

Extract and summarize critical terms from industrial lease agreements. Use for lease review before execution, rent roll audits, tenant comp analysis, due diligence packages, and pre-negotiation prep.

## Extraction Categories

**Property & Parties**
- Landlord, tenant, guarantor, location, SF, facility type

**Temporal Elements**
- Commencement/expiration dates, option structures with notice requirements, early exit clauses

**Rent Framework**
- Base rates, escalation schedules, abatement periods, expense structure (NNN/gross/modified gross)

**Operational Specifics**
- Permitted uses, hazmat policies, hours constraints, parking provisions

**Legal Safeguards**
- Assignment consent rules, default remedies, security deposit, TI allowances

## Risk Flags to Surface
- Rent drops approaching expiration
- Weak or missing guarantees
- Co-tenancy dependencies
- Unrestricted assignment rights
- Hazmat liability gaps
- Expiring CAM limitations

## Output Format
Structured abstract with rent schedule table and highlighted concerns section for quick decision-making.
