# Data: Create Visualization

Create charts and visualizations for industrial real estate reporting. Use for quarterly reports, IC presentations, LP decks, and market analysis.

## Chart Type Guide

| Chart Type | Best For |
|-----------|---------|
| Line chart | Occupancy over time, rent growth trends |
| Bar chart | Property comparison, market vs. portfolio |
| Waterfall | NOI bridge, sources & uses |
| Pie/donut | Portfolio allocation by geography or asset type |
| Scatter plot | Vacancy vs. rent growth correlation |
| Heat map | Portfolio scorecard |
| Stacked bar | Composition changes across quarters |

## Design Standards
- Use 2–3 colors maximum; use brand colors if available
- All axes must include units and data source
- No 3D charts (distort perception)
- Include data labels for key values
- Add chart title and "Source: [data source, date]" caption

## Output Formats
1. **Mermaid diagram** — for inline markdown/Notion use
2. **Formatted data table** — for spreadsheet import and manual charting
3. **ASCII representation** — fallback for plain text environments

Each visualization should be accompanied by:
- Written interpretation (2–3 sentences)
- Key finding callout
- Data limitations note if applicable
