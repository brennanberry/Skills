# Sales: Pipeline Review

Review and analyze acquisition or leasing pipelines — status, probability, expected close, and next steps. Role: Asset Manager/Fund Manager. Frequency: Weekly.

## Acquisition Pipeline Stages & Probabilities

| Stage | Probability |
|-------|------------|
| Initial sourcing / awareness | 5–15% |
| Under LOI / soft offer | 25–40% |
| In due diligence | 50–65% |
| PSA executed | 75–85% |
| Hard money / final approval | 90–99% |

## Leasing Pipeline Stages

| Stage | Description |
|-------|------------|
| Initial inquiry | Prospect contacted |
| Tour completed | Space toured |
| Proposal sent | LOI or term sheet out |
| Negotiating | Active back-and-forth |
| LOI executed | Terms agreed |
| Lease drafting | Legal review |
| Executed | Lease signed |

## Weekly Pipeline Report Format
```
PIPELINE REVIEW — [Date]

ACQUISITIONS
Active deals: [#]  |  Probability-weighted value: $[X]M
[Deal Name] — [Stage] — [X]% — [Expected close] — [Next step / owner]

LEASING
Active prospects: [#]  |  Pipeline SF: [X,XXX SF]
[Tenant] — [SF] — [Stage] — [Expected commencement] — [Next step]

PIPELINE HEALTH
Status: [Healthy / At-Risk / Problematic]
- Healthy: Multiple stages represented, steady velocity
- At-Risk: Concentrated in early stages, few near term closes
- Problematic: Empty, all stalled, or only one deal

PRIORITIES THIS WEEK
1. [Action] — [Owner]
2. [Action] — [Owner]
```

## Key Metrics to Track
- Total active deals and probability-weighted value
- Stage distribution (concentrated early = pipeline risk)
- Average days per stage (velocity analysis)
- Win/loss rate by deal source
