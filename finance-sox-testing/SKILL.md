# Finance: SOX Internal Control Testing

Design and execute SOX compliance tests for industrial real estate operations. Use for annual SOX 404 compliance, internal control documentation, and audit readiness. Role: Controller. Frequency: Annual.

## Key Control Domains
1. Revenue / rent collection
2. Accounts payable
3. Payroll
4. Financial close procedures
5. Fixed asset management
6. Treasury operations
7. Financial reporting

## Testing Methodology (5 Steps)
1. **Understand controls** — interviews, walkthrough, process documentation
2. **Sample selection** — risk-based; typically 25–40 items for monthly controls
3. **Test execution** — document evidence for each sample
4. **Record findings** — note exceptions with root cause
5. **Conclude** — effective / ineffective with deficiency classification

## Deficiency Classification
| Level | Definition |
|-------|-----------|
| Control Deficiency | Design gap or operating failure |
| Significant Deficiency | Governance-level concern |
| Material Weakness | Could result in material financial misstatement |

## Deliverables
- Populated Risk & Control Matrix (RCM)
- Completed workpapers per control tested
- Deficiency summary with root cause
- Management remediation plan: owner + due date per finding
