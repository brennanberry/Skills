# Operations: Status Report

Generate progress reports for industrial real estate stakeholders. Covers asset performance, project updates, and fund status. Use for weekly team updates, monthly LP reports, CapEx tracking, and leasing summaries.

## Internal Operations Template

```
PROPERTY STATUS REPORT — [Property Name]
Period: [Month/Week]  |  Prepared by: [Role]  |  Date: [Date]

ESCALATIONS / ISSUES REQUIRING ATTENTION
- [Issue] — Owner: [Name] — Due: [Date]

OCCUPANCY & LEASING
- Current occupancy: X%  (Budget: X%)
- Leasing pipeline: [SF] at [# prospects]
- Executed this period: [SF / tenant name]

OPERATIONS & MAINTENANCE
- Open work orders: [#]  (> 30 days: [#])
- Completed this period: [summary]

FINANCIAL SNAPSHOT
- Collections: $[X] ([X]% of billed)
- NOI (MTD): $[X] vs. budget $[X] ([+/-X]%)

CAPITAL PROJECTS
- [Project]: [% complete] — [budget vs. actual]

OUTLOOK
- [Key priorities next period]
```

## External LP Template
Use the same structure but:
- Replace escalation section with executive summary
- Use measured, professional tone
- Contextualize variances before disclosing them
- Lead with quantitative performance data

## Standards
- Use numbers; avoid vague language ("rents are improving" → "asking rents up $0.15/SF MoM")
- Lead with critical information — do not bury problems
- Flag items requiring stakeholder action explicitly
