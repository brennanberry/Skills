# Finance: Journal Entry Preparation

Prepare, review, and document journal entries for industrial real estate entities — accruals, reclassifications, depreciation, and adjusting entries. Role: Controller. Frequency: Monthly.

## Required Fields (Every Entry)
1. Transaction date
2. Unique reference ID
3. Narrative description (clear, audit-ready)
4. Debit account(s) with GL codes
5. Credit account(s) with GL codes
6. Dollar amount
7. Preparer name and approver name

Supporting documentation is mandatory for every entry.

## Common Entry Types
- Unpaid invoices / accrued expenses
- Monthly depreciation and amortization
- Prepaid cost amortization
- Miscoded transaction corrections
- Intercompany eliminations
- Revenue recognition timing adjustments

## Pre-Approval Checklist
- [ ] Debits = Credits
- [ ] Correct entity assigned
- [ ] Accounting period is open
- [ ] Supporting documents referenced
- [ ] Description is audit-ready (not "misc adjustment")

## Format
```
Date:        [YYYY-MM-DD]
Ref:         [JE-2024-###]
Description: [Clear narrative]
Entity:      [Property LLC / Fund]
Dr  [Account Name] [Code]    $X,XXX
Cr  [Account Name] [Code]    $X,XXX
Support:     [File reference]
Prepared by: [Name]    Approved by: [Name]
```
