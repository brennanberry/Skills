# Data: Statistical Analysis

Apply quantitative methods to industrial real estate datasets. Use for market rent projections, cap rate modeling, absorption analysis, and tenant risk assessment.

## Four Core Analytical Approaches

**1. Descriptive Analysis**
- Count (n), Mean, Median, Std Dev, Min/Max, 25th/75th percentile
- Establishes baseline distribution of the dataset

**2. Time Series Evaluation**
- Track variables longitudinally
- Calculate CAGR: `((End Value / Start Value)^(1/Years)) - 1`
- Identify inflection points where trajectory shifts

**3. Correlation Assessment**
- Measure relationship strength between paired variables (e.g., vacancy and rent growth)
- Coefficient interpretation: |r| > 0.7 = strong, 0.4–0.7 = moderate, < 0.4 = weak
- Note: correlation ≠ causation

**4. Regression Modeling**
- Quantify predictive relationships
- Report: R², p-values, confidence intervals
- Use for forecasting with explicit uncertainty ranges

## Required Report Components
1. Statistical summary table
2. Narrative interpretation (plain language)
3. Visualization guidance
4. Strategic implications for real estate decisions
5. Explicit limitations (data completeness, sample size, time period)

## Common Applications
- Market rent projection by submarket
- Cap rate trend modeling
- Net absorption forecasting
- Tenant credit/risk scoring
