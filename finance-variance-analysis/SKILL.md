# Finance: Variance Analysis

Budget vs. actual variance analysis with driver identification and narrative commentary. Use for monthly reporting, LP communications, and reforecasting. Role: Controller/Asset Manager. Frequency: Monthly.

## Four-Step Methodology

1. **Gather data** — actual P&L (current month, YTD, prior month), budget, known one-time items
2. **Calculate variances** — dollar and percentage by line item; flag favorable (F) vs. unfavorable (U)
3. **Identify material drivers** — investigate items above materiality threshold
4. **Document commentary** — driver, YTD impact, forecast outlook, required action

## Materiality Thresholds by Portfolio Size
| Fund Size | Dollar Threshold | % Threshold |
|-----------|-----------------|-------------|
| < $5M | $2,500 | 10% |
| $5M–$50M | $5,000 | 7% |
| > $50M | $10,000 | 5% |

## Variance Driver Categories
- **Revenue**: Occupancy changes, lease modifications, concessions, timing
- **Expenses**: Timing differences, scope changes, vendor cost increases, one-time items

## Commentary Format (per material variance)
> **[Line Item]**: $[X,XXX] unfavorable ([X]%). Driver: [specific cause]. YTD impact: $[X,XXX]. Outlook: [forecast]. Action: [owner + due date].

## Outputs
- Variance table (budget | actual | $ var | % var | F/U)
- Bullet commentary on each material item
- Executive summary paragraph for LP/management distribution
