# Productivity: Task Management

Organize daily and weekly priorities for industrial real estate professionals across asset management, finance, deals, and LP relations.

## Eisenhower Priority Matrix

| | Urgent | Not Urgent |
|---|---|---|
| **Important** | DO NOW — deadline today, critical path | SCHEDULE — high-value, no deadline yet |
| **Not Important** | DELEGATE — urgent but not your job | ELIMINATE — low value, drop it |

## Daily Structure
```
MUST COMPLETE TODAY (3 max):
1. [Task] — Due: [Time]
2. [Task] — Due: [Time]
3. [Task] — Due: [Time]

IMPORTANT / NOT URGENT:
- [Task]

BLOCKED (waiting on):
- [Task] — Waiting on: [Person/System]

END OF DAY CHECK:
[ ] Task 1  [ ] Task 2  [ ] Task 3
```

## Weekly Planning (Monday)
- One key win for the week: [define it]
- Financial reporting tasks
- Deal / leasing activities
- Operations follow-ups
- Team communication items

## Role-Specific Focus Areas

**Asset Manager**: Property performance reviews, lease renewals, investor updates
**Controller**: Close progress, reconciliations, audit items
**Property Manager**: Work orders, vendor coordination, tenant requests

## Best Use Cases
- Start-of-day prioritization
- Monday morning weekly planning
- Post-meeting action item extraction
- Converting an unorganized task list into an actionable plan
